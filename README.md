# PORT Platform Backend

FONKON Market Development 1.1/1.2 backend foundation.

## Scope
- Customer structured data model
- CV/OT/PI scoring engine
- AQ opportunity funnel
- S/A/B/C/D customer grading
- Red/Yellow/Green alerts
- API-ready service boundary

This repository starts as a framework-first implementation. Database and authentication can be attached without changing the scoring contract.
